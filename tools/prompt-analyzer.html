Gaiish Prompt Analyzer

See which parts of your request are explicit, then decide what to improve. The result is a heuristic, not a validated measurement.

Last updated 2026-08-29 · Author

Private by design: this tool runs in your browser. Your text is not sent to a server for analysis and is never included in analytics events. Session replay is enabled site-wide with all text and form fields masked, so recordings show layout and interactions, not what you type.

Paste a prompt. It will be inspected locally and never submitted.

Heuristic only: this score reflects explicit Gaiish structure. It is not a validated measurement and does not judge truth, quality or model behaviour.
