# Brand image templates

`brand-reference.jpg` is the canonical Gaiish visual reference: deep navy background, a
human profile facing a luminous wireframe AI head, teal/cyan/violet light streams between
them. Use it as the input template when generating any new site imagery.

Guidelines for derived images:

- Palette: deep navy (#04101a–#0b1f33) base, cyan/blue particles, teal and violet accents.
- Theme: human–AI collaboration, communication, clarity.
- No text, logos, or icons baked into the image — headlines are rendered in HTML.
- Wide/cinematic framing with dark negative space where white type sits.

Current and alternate renders:

- `hero-profiles.jpg` — in production as `assets/hero.jpg`.
- `hero-wireframe-head.jpg` — wireframe head right, particle stream flowing left.
- `hero-waveform.jpg` — abstract particle waveform, no figures.
