Learn Gaiish

Four steps, in order. Read the method, write a BASIC prompt, upgrade it to PRO, then check it with the analyzer.

Last updated 2026-08-29 · Author

Step 1 — Learn the six components

Intent, context, instruction, constraints, result and validation. Each one answers a question the model cannot answer for itself.

  1. IntentWhat are you trying to accomplish?
  2. ContextWhat does the AI need to know?
  3. InstructionWhat should the AI do?
  4. ConstraintsWhat rules, limits, tone, format, requirements or exclusions apply?
  5. ResultWhat should the finished output look like?
  6. ValidationHow should the AI verify the result satisfies the request?

The Gaiish Method

Step 2 — Write a Gaiish BASIC prompt

Goal + Context + Action + Output. Four lines, no ceremony. Use it for everyday requests where you would otherwise type a single sentence.

GOAL: what you are trying to accomplish
CONTEXT: what the model cannot infer
ACTION: what you want it to do
OUTPUT: the artefact you expect back

Gaiish BASIC

Step 3 — Upgrade to Gaiish PRO when it matters

Role, Intent, Context, Knowledge, Constraints, Process, Output, Validation. Use it when the work is going to someone else, when the output feeds a system, or when being wrong is expensive.

Gaiish PROGaiish Syntax

Step 4 — Check and refine

Paste your prompt into the analyzer to see which components are thin, then keep what worked and correct the specific part that did not. Refine rather than restart.
