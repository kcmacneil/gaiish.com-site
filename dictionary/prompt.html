Prompt

The input a person or system sends to a generative AI model.

Last updated 2026-08-29 · Author

General AI term

The input a person or system sends to a generative AI model.

A prompt may contain a question, instructions, source material, examples, constraints and an output request. In a conversation, previous messages and system instructions may also shape what the model receives.

Gaiish is a way to structure the meaningful parts of a prompt. It does not require special software or a separate model language; the declarations are written in ordinary words.
